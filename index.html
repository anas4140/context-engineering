Quick Start

Up and running in 3 steps

# 1. Clone and install git clone https://github.com/anas4140/context-engineering.git pip install -r requirements.txt # 2. Add your Anthropic API key cp .env.example .env # → paste ANTHROPIC_API_KEY=sk-ant-... into .env # 3. Run your first lesson python3 code/module1/lesson1_context_demo.py

Requires Python 3.10+ and an Anthropic API key. No prior AI or ML experience required.
